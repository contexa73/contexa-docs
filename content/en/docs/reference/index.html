Module map

The labels on the cards mean: CONTEXA_OWNED only: works only when Contexa owns login (FULL or contexa.bridge.ownership=CONTEXA_OWNED). Optional, off by default: connects to an outside service and works only when turned on. Extension point: the OSS has only the contracts; the execution is yours to build or needs the enterprise module.
