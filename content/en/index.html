Open-source AI security for Spring Security

After sign-in, stop the attacks that look like normal work

Stolen accounts, insiders and AI agents that go too far all pass sign-in and permission checks. Contexa's AI judges each protected request by usual behavior and company records, then allows it, asks for more authentication, or blocks it.

Get started GitHub
  • Apache 2.0 open source
  • A library for Spring Boot apps
  • People and AI agents

What makes Contexa different

Existing security asks who signed in and what they may do. Contexa asks the next question: is this request really that person's own work?

Judges by context

Instead of fixed rules, AI judges with the user's usual behavior, the session's flow and company records such as approvals and tickets.

Decision engine →

AI agents as security subjects

An agent's requests are judged apart from people's, together with whose delegation it acts under and how far it reaches.

Agent security →

Decisions you can verify

The prompt the model received and its decision are signed and sealed, so you can later confirm nothing changed or run them again.

Add it to the app you have

Your sign-in and Spring Security setup stay as they are.

  1. Add the spring-boot-starter-contexa dependency
  2. Connect a dedicated database and an AI model
  3. Add @EnableAISecurity and @Protectable
Get started
Java 
@SpringBootApplication
@EnableAISecurity
public class MyApplication { ... }

@Service
public class ReportService {

    @Protectable
    public Report export(Long customerId) { ... }
