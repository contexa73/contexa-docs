Spring Security를 위한 오픈소스 AI 보안

로그인 이후, 정상처럼 보이는 공격을 막습니다

탈취된 계정, 내부자, 선을 넘은 AI 에이전트는 로그인과 권한 검사를 그대로 통과합니다. Contexa는 보호하는 요청마다 평소 행동과 회사 기록을 근거로 AI가 판단해 허용 · 추가 인증 · 차단을 정합니다.

시작하기 GitHub
  • Apache 2.0 오픈소스
  • Spring Boot 앱에 붙이는 라이브러리
  • 사람과 AI 에이전트 모두

Contexa가 다른 점

기존 보안은 누가 들어왔는지, 무엇을 할 수 있는지를 봅니다. Contexa는 그다음 질문, 지금 이 요청이 정말 그 사람의 일인지를 봅니다.

맥락으로 판단합니다

기존 앱에 그대로 붙입니다

앱의 로그인과 Spring Security 설정은 바꾸지 않습니다.

  1. 의존성 spring-boot-starter-contexa 추가
  2. 전용 DB와 AI 모델 연결
  3. @EnableAISecurity와 @Protectable 달기

@EnableAISecurity
