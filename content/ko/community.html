커뮤니티

CONTEXA 커뮤니티는 코드 기여, 이슈 보고, 질문을 환영합니다. Spring Boot용 인증 이후 런타임 보안을 함께 발전시킵니다.

기여하기

CONTEXA는 오픈 소스 프로젝트이며, 버그 수정과 문서 개선부터 새로운 기능과 아키텍처 개선까지 모든 종류의 기여를 환영합니다.

1

Fork & Clone

GitHub에서 리포지토리를 Fork한 뒤 로컬에 Clone합니다.

Shell 
git clone https://github.com/your-username/contexa.git
cd contexa
git checkout -b feature/your-feature-name
2

빌드 & 테스트

변경하기 전에 기존 테스트가 모두 통과하는지 확인합니다. CONTEXA는 Gradle로 빌드합니다.

Shell 
./gradlew build
./gradlew test
3

Pull Request 제출

브랜치를 Push한 뒤 main 브랜치로 Pull Request를 엽니다. 변경 사항을 명확하게 설명하고 관련 이슈를 함께 적습니다.

GitHub에서 연결하기

CONTEXA 프로젝트는 GitHub에서 운영됩니다. 참여할 수 있는 주요 채널은 다음과 같습니다.

이슈

버그 보고, 기능 요청, 기존 이슈 확인에 씁니다. 라벨로 모듈이나 우선순위별로 필터링할 수 있습니다.

커뮤니티 vs 엔터프라이즈

CONTEXA Community Edition은 Apache License 2.0에 따라 무료 오픈 소스로 제공됩니다. Enterprise Edition은 운영 환경의 핵심 업무를 위한 추가 기능을 제공합니다.

기능 Community Enterprise
Identity DSL (Form, REST, OTT, Passkey, MFA) 포함 포함
XACML Policy Engine & @Protectable 포함 포함
Zero Trust 판정(허용 · 추가 인증 · 검토 보류 · 차단) 포함 포함
AI 판정 엔진(1차 · 2차 분석) 포함 포함
운영 모드(끔 · 관찰 · 적용) 포함 포함
SSE Streaming & PgVector RAG 포함 포함
Standalone & Distributed 모드 포함 포함
에이전트 보안(위임 · 책임자 확인 · 정지 · 호출 상한) 포함 포함
봉인 증거(판정의 입력을 보관하고 변경 여부를 확인)와 프롬프트 품질 보증(새 프롬프트 버전의 판정 품질을 측정) 포함 포함
기존 로그인과 연결하기(인증 브리지) 포함 포함
SOAR (Security Orchestration, Automation & Response) — 포함
MCP Server 통합 — 포함
Admin Console & Policy Studio 제한적 전체
우선 지원 & SLA 커뮤니티 전담
라이선스 Apache 2.0 Commercial
